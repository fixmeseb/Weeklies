def record_analytics_snapshot(rtr_id):

Save today's figures for a restaurant (proj2.ordering.restaurant_metrics).

There is one snapshot per restaurant per day: a later call the same day replaces that day's row instead of adding another, so the history has one point per day however often orders change. Cancelled orders are left out of revenue.

Args: rtr_id (int): The restaurant ID to record analytics for.

Returns: bool: True if snapshot was recorded successfully, False otherwise.

@app.route('/menu/order-plan', methods=['POST'])
def order_plan_days():

Order every planned meal from start_date for days days that is not ordered yet.

Each meal becomes its own order, due at the user's time for that meal on its day, so the restaurant sees when it is for. Meals that cannot be ordered (sold out, closed then, an allergen, a day already past) are skipped and reported; the rest are placed. Fields: start_date, days, meal1..3 (or JSON number_of_days / meal_numbers), delivery_type and tip (per order).
